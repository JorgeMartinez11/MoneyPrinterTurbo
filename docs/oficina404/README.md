# La Oficina 404

Documentación del proyecto **La Oficina 404**, una adaptación de MoneyPrinterTurbo orientada a crear vídeos verticales cortos para Instagram Reels, TikTok y YouTube Shorts.

## Documentos

- `00-vision.md`: visión, objetivo y principios del proyecto.
- `01-channel-bible.md`: temática, tono, humor y reglas editoriales.
- `02-visual-style.md`: identidad visual y reglas para generación de imágenes.
- `03-characters.md`: reparto recurrente y fichas de personajes (pendiente).
- `04-video-format.md`: estructura final de los vídeos (pendiente de validar con pilotos).
- `05-content-rules.md`: reglas editoriales y criterios de selección de temas (pendiente).
- `06-prompts.md`: prompts canónicos de guion, escenas e imágenes (pendiente).
- `07-pipeline.md`: pipeline técnico de generación y publicación (pendiente).

## Assets

Los recursos visuales propios del canal viven en `assets/oficina404/`:

- `branding/`: logo, avatar y branding.
- `references/`: imágenes canónicas usadas como referencia visual.
- `characters/`: hojas de personaje y referencias individuales.
- `backgrounds/`: escenarios recurrentes de la oficina.

## Estado

Primera fase: definir la identidad del canal y producir varios vídeos piloto manualmente antes de automatizar el pipeline.

> Regla actual: no modificar todavía el código funcional de MoneyPrinterTurbo hasta validar el formato con vídeos reales.
