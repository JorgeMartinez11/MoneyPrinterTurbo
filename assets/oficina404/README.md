# Assets — La Oficina 404

Recursos visuales propios del canal.

## Estructura

- `branding/`: avatar, logo, banners y elementos de marca.
- `references/`: referencias visuales canónicas del estilo.
- `characters/`: hojas y referencias de personajes recurrentes.
- `backgrounds/`: escenarios y fondos recurrentes.

No guardar aquí outputs temporales de cada vídeo. Esta carpeta debe contener únicamente recursos reutilizables y referencias canónicas.
